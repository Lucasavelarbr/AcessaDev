# Acessa Dev

O Acessa Dev é uma plataforma educativa sobre acessibilidade digital, criada para apoiar desenvolvedores na construção de sites mais inclusivos.

## Conteúdos

- Guias sobre acessibilidade digital
- HTML semântico
- Formulários acessíveis
- Navegação por teclado
- Testes de acessibilidade
- Ferramentas e recursos para desenvolvimento inclusivo

## Tecnologias

- HTML5 semântico
- CSS3 responsivo
- JavaScript puro
- Bootstrap Icons

## Objetivo

Tornar conceitos de acessibilidade mais práticos, apresentando explicações simples, exemplos de código e recomendações que podem ser aplicadas em projetos reais.

## Como visualizar

Clone ou baixe este repositório e abra o arquivo `index.html` no navegador.

Para uma experiência melhor durante o desenvolvimento, use uma extensão de servidor local, como o Live Server no VS Code.
