Formulários

Formulários acessíveis

Aprenda a construir formulários intuitivos, acessíveis e compatíveis com leitores de tela.

11 min de leitura

Nesta página você vai aprender:

  • Como utilizar labels corretamente
  • Como criar campos obrigatórios
  • Como trabalhar com mensagens de erro
  • Como agrupar campos relacionados
  • Como melhorar a navegação por teclado

Use labels corretamente

Todo campo de formulário deve possuir uma identificação clara para que o usuário saiba qual informação deve ser preenchida.

A forma mais adequada é utilizar o elemento <label> associado ao campo.

Exemplo acessível

<label for="email">E-mail</label>

<input type="email" id="email" name="email">

Indique campos obrigatórios

Quando uma informação é obrigatória, isso precisa estar claro para todas as pessoas, inclusive para quem utiliza tecnologias assistivas.

Exemplo

<label for="nome">Nome completo</label>

<input type="text" id="nome" name="nome" required>

Mensagens de erro

Mensagens de erro devem explicar claramente o que aconteceu e, principalmente, como o usuário pode corrigir o problema.

Exemplo

<label for="email">E-mail</label>

<input type="email" id="email" aria-describedby="email-error" aria-invalid="true">

<span id="email-error">Informe um endereço de e-mail válido.</span>

Pense na navegação por teclado

Todos os campos e controles devem poder ser acessados utilizando apenas o teclado.

A ordem de navegação também precisa fazer sentido para quem está utilizando a interface.

Pense assim

Se uma pessoa consegue preencher seu formulário utilizando apenas o teclado e um leitor de tela, você está no caminho certo.
